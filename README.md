## 📌 Project Overview

This project is part of my Python learning journey. It focuses on understanding and practising Python data structures, including Lists, Dictionaries, and Sets, along with conditional statements.

The assignment includes practical examples of creating, accessing, modifying, and performing operations on different data structures.

## 🎯 Objectives

- Understand Python List creation, modification, and accessing elements.
- Perform List operations such as append, insert, remove, pop, extend, and sort.
- Create and manipulate Dictionaries using keys, values, and items.
- Understand Sets and their properties, including unique elements.
- Perform Set operations such as Union and Intersection.
- Apply conditional statements using if, elif, and else.
- Develop logical thinking through practical Python programs.

## 🛠️ Concepts Covered

### 1. Lists
- List creation
- Adding elements using `append()` and `insert()`
- Removing elements using `remove()` and `pop()`
- Extending lists using `extend()`
- Sorting elements in descending order
- Finding maximum, minimum, and sum
- Accessing list elements using indexing and slicing
- Reversing a list

### 2. Dictionaries
- Dictionary creation
- Accessing dictionary values
- Adding new key-value pairs
- Updating existing values
- Using `keys()`, `values()`, and `items()` methods

### 3. Sets
- Set creation
- Understanding duplicate element removal
- Understanding unordered collections
- Exploring set immutability with respect to indexing and item assignment
- Performing Union and Intersection operations

### 4. Conditional Statements
- Using `if`, `elif`, and `else`
- Getting user input
- Validating score ranges
- Categorizing performance based on scores
- Displaying appropriate messages based on conditions
